# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

👉 https://jitbhatiya.github.io/tic-tac-toe-game/

## ✨ Features

- Two-player gameplay
- Winner detection
- Draw detection
- Reset/New Game
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
